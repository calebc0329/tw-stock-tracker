## 🧭 四大交易模式（適應不同投資週期）

由於每位投資人的持有時間與風險承受度不同，系統提供 4 種可切換的決策模式：

1. **綜合評分模式 (Consensus - 推薦預設)**
   * 同時權衡**均線趨勢 (35%)**、**動能交叉 (30%)**、**乖離超買超賣 (25%)** 與 **成交量 (10%)**。
   * 給予 -100 到 +100 的量化多空分數，提供最全面的整體評估。
2. **波段操作模式 (Swing Trading)**
   * 偏重**日 KD (9,3,3) 黃金/死亡交叉** 與 **突破/跌破月線 (MA20)**。
   * 適合有盯盤習慣、想掌握波段起漲點與回檔點的靈活交易者。
3. **中長線趨勢模式 (Trend Following)**
   * 關注**月線 (MA20)** 與 **季線 (MA60 - 生命線)** 多頭排列。
   * 過濾短線震盪雜訊，只要大多頭未破便續抱，適合波段存大波段投資人。
4. **存股低接模式 (DCA Dip Buying)**
   * 尋找**負乖離 (BIAS20 < -3%)** 與 **RSI 超賣 (<40)** 的逢低分批加碼機會。
   * 適合定期定額、不追高、專門撿便宜的長期投資者。

## 💡 核心功能

* **🎯 即時決策訊號**：
  * 強烈買進 (Strong Buy)
  * 偏多買進 / 分批進場 (Accumulate)
  * 觀望中立 / 續抱持有 (Hold)
  * 偏空調節 / 減碼出場 (Trim / Take Profit)
  * 強烈賣出 / 空手避險 (Strong Sell / Exit)
* **🛡️ 實戰價位指引**：系統根據 ATR 波動度與關鍵均線，自動推算「防守停損參考點」與「波段停利目標點」。
* **⚠️ 風險特別警示**：針對 `00631L` 提示槓桿耗損風險與停損紀律；針對 `009800` 提示美股連動與匯率變數。
* **📈 互動式 Plotly K線與指標圖**：
  * 主圖直接標記買進（綠色 ▲）與賣出（紅色 ▼）時點。
  * 附帶日 KD 與 MACD 柱狀體次圖。
* **📊 歷史策略回測模擬**：
  * 比較策略淨值曲線 vs 單純買進持有 (Buy & Hold) 基準。
  * 統計超額報酬 (Alpha)、最大回撤 (MDD)、勝率及歷史交易清單。
* **🔍 多標的橫向大盤點**：一鍵將 0050、009800、2330、00631L 等並列評比，掌握資金輪動。
* **📲 LINE 官方推播整合**：全面採用 LINE Messaging API，可一鍵測試、發送日報，或透過排程每日 14:00 自動推播至手機。

## 📲 LINE 推播設定教學 (LINE Messaging API)

> 註：LINE Notify 已於 2025 年 3 月底終止，本系統採用官方建議之 **LINE Messaging API (官方帳號)**，每月提供免費推播額度，個人使用完全足夠。

1. **取得 Token 與 User ID**：
   * 前往 [LINE Developers Console](https://developers.line.biz/) 並登入個人 LINE。
   * 建立一個 **Provider**，並在其下建立一個 **Messaging API Channel**。
   * 在 **Messaging API** 頁籤底部點選 **Issue** 取得 **Channel Access Token (Long-lived)**。
   * 掃描該頁面上的 **QR Code**，將您的機器人帳號加為好友。
   * 在 **Basic settings** 頁籤底部複製您的 **Your user ID**（以 `U` 開頭）。
2. **在 Web 介面設定**：
   * 開啟儀表板切換至 **「📲 LINE 即時推播設定」** 分頁。
   * 貼上 Token 與 User ID，點擊 **儲存設定**。
   * 點選 **「🔔 發送連線測試訊息」**，確認手機 LINE 收到通知。
3. **設定每日收盤自動推播 (Mac Crontab)**：
   * 終端機執行 `crontab -e` 加入以下排程（台股每週一至週五 14:00 自動推播）：
     ```bash
     0 14 * * 1-5 /Users/calebchen/.gemini/antigravity/scratch/tw-etf-tracker/.venv/bin/python /Users/calebchen/.gemini/antigravity/scratch/tw-etf-tracker/daily_alert.py >> /Users/calebchen/.gemini/antigravity/scratch/tw-etf-tracker/cron.log 2>&1
     ```
